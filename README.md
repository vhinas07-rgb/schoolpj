Course Management Website

A web-based Course Management System developed using Python and Django.

This project was created as a practical exercise to improve my Django development skills and understand the fundamentals of backend web development.
Features

    Display available courses

    View course details

    Create new courses

    Update existing courses

    Delete courses

    Filter courses by category

    Upload course images

    Manage course information, including title, teacher, price, and duration

    Contact form



Installation and Setup:

Clone the repository:

git clone (https://github.com/vhinas07-rgb/schoolpj)

Navigate to the project directory:

cd schoolpj

Create a virtual environment:

python -m venv venv

Activate the virtual environment (Windows):

.venv\Scripts\activate

Install Django:

pip install django

Apply database migrations:

python manage.py migrate

Run the development server:

python manage.py runserver

Open the following address in your browser:

http://127.0.0.1:8000/

# وب‌سایت مدیریت دوره‌های آموزشی (Course Management Website)

یک سیستم مدیریت دوره‌های آموزشی تحت وب که با استفاده از زبان برنامه‌نویسی Python و فریم‌ورک Django توسعه داده شده است.

این پروژه به‌عنوان یک تمرین عملی با هدف تقویت مهارت‌های توسعه با Django و آشنایی با مفاهیم پایه توسعه بک‌اند طراحی و پیاده‌سازی شده است.

## امکانات پروژه (Features)

- نمایش دوره‌های آموزشی موجود
- مشاهده جزئیات هر دوره
- ایجاد دوره‌های آموزشی جدید
- ویرایش دوره‌های موجود
- حذف دوره‌های آموزشی
- فیلتر کردن دوره‌ها بر اساس دسته‌بندی
- بارگذاری تصاویر دوره‌ها
- مدیریت اطلاعات دوره‌ها شامل عنوان، مدرس، قیمت و مدت زمان
- فرم تماس با ما

## نصب و راه‌اندازی (Installation and Setup)

**۱. دریافت پروژه از GitHub:**

```bash
git clone https://github.com/vhinas07-rgb/schoolpj.git
```

**۲. ورود به پوشه پروژه:**

```bash
cd schoolpj
```

**۳. ایجاد محیط مجازی:**

```bash
python -m venv venv
```

**۴. فعال‌سازی محیط مجازی در ویندوز:**

```powershell
.venv\Scripts\activate
```

**۵. نصب Django:**

```bash
pip install django
```

**۶. اجرای Migrationها و اعمال تغییرات پایگاه داده:**

```bash
python manage.py migrate
```

**۷. اجرای سرور توسعه:**

```bash
python manage.py runserver
```

**۸. باز کردن آدرس زیر در مرورگر:**

http://127.0.0.1:8000/
